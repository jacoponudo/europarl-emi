# europarl-emi

Evidence-minus-intuition (EMI) scoring of English-language European Parliament interventions.

## Struttura
- `data/raw/` – dati originali, mai modificati (corpus, file MEP, lessici)
- `data/interim/` – output intermedi rigenerabili
- `data/processed/` – dataset finali per l'analisi
- `models/` – classificatore dei testi procedurali
- `notebooks/legacy/` – notebook originali (Colab), solo come riferimento
- `src/europarl_emi/` – codice della pipeline
- `results/` – figure e tabelle
